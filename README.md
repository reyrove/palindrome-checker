# Palindrome Checker

A simple, clean web application that checks whether a given text string is a palindrome.

[Live Demo](https://reyrove.github.io/palindrome-checker/)

## Features

- Real-time palindrome validation
- Case-insensitive checking
- Ignores special characters and spaces
- User-friendly interface with responsive design
- Clear visual feedback on results

## How It Works

1. Enter any text in the input field
2. Click the "Check" button
3. The application will display whether your input is a palindrome

The checker removes all non-alphanumeric characters (spaces, punctuation, symbols) and converts everything to lowercase before comparing the string forward and backward.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/reyrove/palindrome-checker.git
   ```
2. Open `index.html` in any modern web browser
